# Скрипт автосортировки файлов

Автоматически сортирует файлы в указанной директории по категориям на основе их расширений.

## Возможности

- 📁 Автоматическое определение типа файла по расширению
- 🗂️ Создание папок по категориям (Изображения, Видео, Аудио, Документы и т.д.)
- 🔄 Перемещение файлов в соответствующие папки
- 🔍 Режим предпросмотра (dry-run) для безопасной проверки
- 📊 Вывод статистики по обработанным файлам
- 🔁 Поддержка рекурсивной обработки подпапок
- ⚠️ Автоматическое разрешение конфликтов имен файлов

## Категории файлов

- **Изображения**: jpg, png, gif, bmp, svg, webp и др.
- **Видео**: mp4, avi, mkv, mov, wmv и др.
- **Аудио**: mp3, wav, flac, aac, ogg и др.
- **Документы**: pdf, doc, docx, xls, xlsx, txt и др.
- **Архивы**: zip, rar, 7z, tar, gz и др.
- **Программы**: exe, msi, deb, rpm, apk и др.
- **Код**: py, js, html, css, java, cpp и др.
- **Таблицы**: csv, xls, xlsx
- **Презентации**: ppt, pptx, odp
- **Другое**: файлы с неизвестными расширениями

## Установка

Требуется Python 3.6 или выше. Дополнительные библиотеки не требуются.

## Использование

### Базовое использование

```bash
# Сортировка текущей директории
python autosort.py

# Сортировка указанной директории
python autosort.py "C:\Downloads"
```

### Режим предпросмотра

Перед реальной сортировкой рекомендуется использовать режим предпросмотра:

```bash
python autosort.py --dry-run
```

Это покажет, какие файлы будут перемещены и куда, без фактического перемещения.

### Рекурсивная обработка

Для обработки файлов во всех подпапках:

```bash
python autosort.py --recursive
```

### Комбинирование опций

```bash
# Предпросмотр с рекурсивной обработкой
python autosort.py "C:\Downloads" --dry-run --recursive
```

## Примеры

### Пример 1: Сортировка папки Загрузки

```bash
python autosort.py "C:\Users\Username\Downloads"
```

Результат:
```
✓ Перемещен: photo.jpg -> Изображения/
✓ Перемещен: video.mp4 -> Видео/
✓ Перемещен: document.pdf -> Документы/
✓ Перемещен: archive.zip -> Архивы/
```

### Пример 2: Предпросмотр перед сортировкой

```bash
python autosort.py --dry-run
```

Вывод:
```
[ПРЕДПРОСМОТР] photo.jpg -> Изображения/photo.jpg
[ПРЕДПРОСМОТР] video.mp4 -> Видео/video.mp4
...
```

## Безопасность

- Скрипт не удаляет файлы, только перемещает их
- Если файл с таким именем уже существует в целевой папке, добавляется номер
- Рекомендуется сначала использовать `--dry-run` для проверки
- Файлы в папках категорий не обрабатываются повторно

## Примечания

- Скрипт создает папки категорий в указанной директории
- Файлы без расширения попадают в категорию "Другое"
- Регистр расширений не имеет значения (.JPG и .jpg обрабатываются одинаково)
